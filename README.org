L’échelle pour noter chaque TP.

- 50% qualité du code (voir standards).
- 50% qualité des résultats (graphiques et réponses aux questions).
- quelques codes et graphiques mais pas correct, -5 to -10.
- code ou graphique manquant, -10 to -20.
- code et graphique manquant, -20 to -40.
